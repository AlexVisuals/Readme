## Acerca de

Soy desarrollador web freelance en Barcelona. Después del **CFGS de Desarrollo de Aplicaciones Web**, con prácticas duales en **Animm**, este año he empezado el **Grado en Multimedia en la UOC** para completar el otro lado: diseño, interacción y contenido audiovisual, para que lo que programo no solo funcione, sino que también se vea y se sienta bien.

Diseño y desarrollo webs a medida con **Astro, React y Tailwind CSS**, y en el backend trabajo con **Python (Django, FastAPI)**, **.NET** y **Supabase**. Ahora trabajo como freelance mientras estudio y busco mi próximo equipo.
